# فاحص الوايفاي

سكربت بايثون واحد يفحص الوايفاي ويطلع لك تقرير بالأشياء اللي تبطّي الشبكة. يشتغل على Windows وmacOS وLinux، وما يحتاج تثبيت أي مكتبات.

## التشغيل
1. ثبّت Python 3 من https://www.python.org (في ويندوز اختر "Add Python to PATH").
2. نزّل `wifi_diag.py`، وشغّله وأنت متصل بالوايفاي وقريب من المكان اللي تحس فيه بالبطء:
   ```
   python wifi_diag.py
   ```
   (في ماك ولينكس: `python3 wifi_diag.py`)
3. الفحص ياخذ دقيقة إلى دقيقتين، وبعدها ينحفظ التقرير في `wifi_report.txt`.

خيارات: `--no-scan` بدون مسح الأجهزة، و`--no-speed` بدون اختبار السرعة.

## وش يفحص
- قوة الإشارة، الحيز (2.4/5GHz)، عرض القناة، وسرعة الربط مع الراوتر
- ازدحام القنوات وشبكات الجيران، ويقترح لك أفضل قناة
- التأخير وفقدان الحزم للراوتر وللإنترنت، عشان يحدد إذا المشكلة من الوايفاي ولا من المزوّد
- سرعة DNS
- سرعة التحميل والرفع، ويقيس Bufferbloat (يعني إذا التأخير يرتفع وقت التحميل)
- الأجهزة المتصلة بالشبكة

> ملاحظة: في ويندوز 11 لازم تفعّل خدمة الموقع (Location) عشان يقدر يشوف الشبكات المحيطة. وفي ماك الجديد ممكن يطلع اسم الشبكة مخفي، وهذا ما يأثر على الفحص.
